# Vue3-manage-system

基于 Vue3 + pinia + Element Plus 的后台管理系统解决方案。

[仓库链接](https://github.com/Chuiyun217/vue3-manage-systeam)



## 前言

该项目仅用于学习，展示vue3开发后台管理项目，上手简单，开发快速，二次开发度高，适合用作基础模版。



## 功能

- [x]  Element Plus
- [x]  vite 3
- [x]  pinia
- [x]  登录/注册
- [x]  Dashboard
- [x]  表格/表单
- [x]  图表 📊
- [x]  三级菜单



## 安装步骤

因为使用 vite3，node 版本需要 14.18+

```
git clone https://github.com/Chuiyun217/vue3-manage-systeam.git      // 把模板下载到本地
cd vue3-manage-system    // 进入模板目录
npm install         // 安装项目依赖，等待安装完成之后，安装失败可用 cnpm 或 yarn

// 运行
npm run dev
```
